# Handoff template

## Scope

State the requested outcome and distinguish live, fixture-only, partial, and deferred
behavior.

## Files changed

List files by subsystem and call out any concurrent-agent ownership or preserved user
changes.

## Validation

Give exact commands and outcomes. Include the one-command gate for implementation work,
or explain precisely why it was not run.

## Decisions and invariants

List new decisions, superseded decisions, and trust boundaries that future work must
preserve. Update `decisions.md` before using this section.

## Remaining risks

List concrete blockers, known gaps, external dependencies, and whether each is enforced
or currently relies on convention.

## Next action

Give the highest-value next step and its intended branch/PR target.
